# Changelog

## 1.0.0-rc1

Initial reusable property-browser utility.

- Headless property model
- Built-in editor factory
- Text, numeric, Boolean, choice, color, slider, vector and curve editors
- Custom editor registration
- Collapsible groups
- Filter/search
- Mixed, inherited, reset and validation states
- Preview and commit event separation
- Alternate row shading
- System, Light and Dark palettes
- Active-editor virtualization
- Demo and model tests
