# UiDesigner CLI

Headless access to the same session, catalog, command, theme, validation and code-generation services used by the graphical application and MCP host.

Commands:

```text
uidesigner-cli list-controls
uidesigner-cli validate <project-or-design.json>
uidesigner-cli schema <control-type>
uidesigner-cli set <project> <node-id> <property> <json-value>
uidesigner-cli theme-set <project> <property> <json-value>
uidesigner-cli generate <project> <output-folder> [class-name]
uidesigner-cli migrate <legacy-design.json> <project.uidesign.json>
```
